## Kaynak politikası

Bu klasörde yalnız 11. sınıf resmî öğretim programı kaynakları tutulur. Ders kitabı, textbook coverage, gap veya production çıktıları curriculum source bundle içine eklenmez.

Resmî program tema sayfalarındaki 43 saat öğretim süresi kaynak gerçeğidir. Proje planlama modelinde buna tema başına 2 saat okul temelli planlama eklenerek 45 saatlik tema bloğu kullanılır; bu 2 saat ayrı pedagojik katmandır.
