# TDE_12 source_docs

12. Sınıf Türk Dili ve Edebiyatı için resmî kaynak snapshot'ları bu klasörde tutulur.

Kaynak eklerken:

- öğretim programı ve ders kitabını birbirinden ayır,
- tema/ünite kimliğini içerikten doğrula,
- dosya adını içerik doğrulandıktan sonra normalize et,
- SHA-256 fingerprint üretmeden canonical freeze verme,
- başka sınıfların içeriğini kaynak olarak kullanma.
